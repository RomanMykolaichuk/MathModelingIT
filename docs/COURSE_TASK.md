# Завдання на розроблення дисципліни

## 1. Призначення

Розробити сучасну практико- та дослідницько-орієнтовану дисципліну з математичного моделювання для **ад’юнктів**, у якій Python використовується як наскрізний інструмент реалізації, дослідження, перевірки та представлення математичних моделей.

Офіційні назви тем і занять **не змінюються**.

## 2. Методична ідея

Єдина логіка кожного заняття:

1. прикладна або наукова проблема;
2. математична постановка;
3. змінні, параметри, обмеження, критерії;
4. Python-реалізація;
5. обчислювальний експеримент;
6. аналіз результатів;
7. візуалізація;
8. інтерпретація;
9. науковий висновок;
10. фіксація умов відтворення експерименту.

Python не є самоціллю. Код має бути безпосереднім продовженням математичної моделі.

## 3. Особливість цільової аудиторії

Оскільки дисципліна призначена для ад’юнктів, кожне заняття повинно поступово формувати не лише навичку розв’язування навчальної задачі, а й здатність застосовувати математичне моделювання у власному дисертаційному дослідженні.

Тому обов’язковими компонентами є:

- постановка дослідницького питання;
- явні припущення та межі моделі;
- параметричні експерименти;
- аналіз чутливості;
- перевірка та валідація;
- відтворюваність;
- коректна інтерпретація результату;
- відокремлення результату моделі від реального висновку про досліджувану систему.

## 4. Навчальні теми та заняття

### Тема 1. Теоретичні основи застосування математичного моделювання

1. Форма і принципи представлення математичних моделей.
2. Класифікація математичних моделей.
3. Організація математичного моделювання.
4. Класифікація методів математичного моделювання.

### Тема 2. Комп'ютерні технології обчислень в математичному моделюванні

1. Задачі оптимізації в середовищі VS Code.
2. Математична модель транспортної задачі.
3. Математичні моделі задач нелінійного програмування.
4. Математичне моделювання із застосуванням методів мережевого планування.
5. Засоби розв’язування задач множинного вибору.
6. Системи комп'ютерної математики та їх можливості для математичного моделювання.
7. Використання систем комп’ютерної математики в наукових дослідженнях.

## 5. Наскрізний кейс

Базовий навчальний кейс: **моделювання розподілу, переміщення та використання обмежених ресурсів у складній системі**.

Він ускладнюється протягом курсу:

- параметрична модель;
- детермінована і стохастична версії;
- оптимальний розподіл;
- транспортна модель;
- нелінійна ефективність;
- мережеве планування;
- багатокритеріальний вибір;
- повний відтворюваний computational experiment.

Кейс має залишатися достатньо загальним, щоб його можна було адаптувати до різних наукових предметних областей ад’юнктів.

## 6. Обов’язкові артефакти кожного заняття

Для кожного з 11 занять мають бути створені:

- `README.md` / lesson brief;
- 2 навчальні питання;
- математична постановка;
- короткий теоретичний матеріал;
- Python notebook;
- за потреби окремі `.py` модулі;
- вхідні дані або генератор синтетичних даних;
- практичне завдання;
- очікуваний результат;
- контрольні питання;
- інструкція викладача;
- критерії перевірки виконання;
- приклад висновку за результатами моделювання.

## 7. Окремий презентаційний контур

Презентація не повинна бути первинним носієм змісту.

Після завершення коду і методичної частини кожного заняття окремо створюються:

- сценарій презентації;
- структура слайдів;
- текстові тези;
- формули та графіки з реального коду заняття;
- візуальні матеріали;
- презентація `.pptx`;
- за потреби PDF-версія.

Графіки, таблиці та числові результати у презентації повинні походити з перевірених notebooks/scripts заняття, а не створюватися вручну.

## 8. Критерій завершеності дисципліни

Дисципліна вважається розробленою, коли всі 11 занять мають перевірений код, відтворювані результати, практичні завдання і методичні матеріали, а для кожного завершеного заняття окремо створена узгоджена презентація.
