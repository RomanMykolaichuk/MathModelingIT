# Rubric — Capstone, 100 балів

| Компонент | Бали |
|---|---:|
| Дослідницьке питання та гіпотеза | 10 |
| Математична модель, припущення, обмеження | 15 |
| Дані та їх походження | 10 |
| Калібрування / computational implementation | 15 |
| Verification | 10 |
| Sensitivity analysis | 10 |
| Uncertainty analysis | 10 |
| Figures / tables / reproducibility metadata | 10 |
| Наукова інтерпретація та limitations | 5 |
| Перенесення на власне дослідження | 5 |

Критичне порушення: подання результатів synthetic/computational model як емпірично підтверджених фактів про реальну систему без відповідних даних і validation.
