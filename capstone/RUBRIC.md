# Rubric — підсумковий проєкт, 100 балів

| Компонент | Бали |
|---|---:|
| Дослідницьке питання та гіпотеза | 10 |
| Математична модель, припущення, обмеження | 15 |
| Дані та їх походження | 10 |
| Калібрування / computational implementation | 15 |
| перевірка | 10 |
| чутливість аналіз | 10 |
| невизначеність аналіз | 10 |
| Figures / tables / відтворюваність metadata | 10 |
| Наукова інтерпретація та limitations | 5 |
| Перенесення на власне дослідження | 5 |

Критичне порушення: подання результатів synthetic/computational модель як емпірично підтверджених фактів про реальну систему без відповідних даних і validation.
