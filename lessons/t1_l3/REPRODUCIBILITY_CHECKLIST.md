# відтворюваність checklist

Перед тим як посилатися на результат обчислювальний експеримент у дисертації, статті або доповіді, перевір:

## дослідницьке питання
- [ ] Чітко сформульоване питання, на яке відповідає експеримент.
- [ ] Визначено, що є вхідні дані, вихідні дані і параметрами.

## дані
- [ ] Вхідні дані збережено окремо від коду.
- [ ] Відоме походження або процедура генерації даних.
- [ ] Формат даних документований.

## модель
- [ ] Математична модель описана формулами або однозначними правилами.
- [ ] Зафіксовані припущення.
- [ ] Зафіксовані межі застосовності.

## Configuration
- [ ] Параметри експерименту винесено в config.
- [ ] Немає критичних «магічних чисел», прихованих у блокнот Jupyter.
- [ ] Для stochastic модель зафіксований seed.

## Execution
- [ ] Є одна команда або чітка процедура повного запуску.
- [ ] Повторний запуск не потребує ручного редагування проміжних файлів.
- [ ] Outputs створюються автоматично.

## перевірка
- [ ] Є хоча б один ручний або аналітичний контрольний випадок.
- [ ] Перевіряються допустимі межі результату.
- [ ] Є unit/sanity tests.

## Metadata
- [ ] Є experiment ID.
- [ ] Зафіксовано config hash.
- [ ] Відомий Git commit.
- [ ] Зафіксовані software dependencies.

## інтерпретація
- [ ] Результат інтерпретований предметно.
- [ ] Відокремлено чисельний результат від висновку.
- [ ] Не робляться твердження, яких модель не дозволяє.

## Publication
- [ ] Можна встановити, яким experiment ID відповідає таблиця або рисунок.
- [ ] Результат можливо перебудувати з репозиторію.
