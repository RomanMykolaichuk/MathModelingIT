## 1. Два взаємодоповнювальні кейси

### Кейс A — прикладна задача з diminishing returns

Є два напрями використання обмеженого ресурсу. Позначимо `x`, `y` — обсяги ресурсу; `R` — загальний доступний ресурс.

Цільова функція:

`F(x,y)=40(1-exp(-0.05x))+35(1-exp(-0.04y))+0.15*sqrt(xy) -> max`

за умов:

`x+y <= R`, `x >= 0`, `y >= 0`.

Перші два доданки моделюють спадну граничну віддачу, третій — слабку синергію між двома напрямами.

Для `R=100` контрольний результат:

- `x ≈ 48.659`;
- `y ≈ 51.341`;
- `F ≈ 74.497`;
- використовується практично весь ресурс.

Цей кейс використовується для вивчення нелінійної цільової функції, `SLSQP`, constraints, feasibility checks і sensitivity analysis.

### Кейс B — deliberately non-convex landscape

Для демонстрації локальних екстремумів використовується спеціально сконструйована навчальна функція:

`G(x,y)=sin(1.7x)cos(1.3y)+0.15x-0.03(x^2+y^2)`

за `-4 <= x,y <= 4`.

Це не прикладна модель реального процесу, а навчальний landscape із кількома локальними максимумами. Його задача — показати:

> `optimizer success = True` не означає автоматично, що знайдено глобальний оптимум.

## 5. Verification

Для прикладної моделі окремо перевіряються `x>=0`, `y>=0`, `x+y<=R` та скінченність objective.

Для non-convex landscape використовуються два незалежні механізми:

1. **multi-start** — локальний solver запускається з різних стартових точок;
2. **grid search** — грубий повний перебір двовимірної області.

Контрольний район найкращого рішення:

`x≈0.956`, `y≈0`, `G≈1.1145`.

## 6. Sensitivity analysis

Контрольні результати для прикладної моделі:

| R | x* | y* | F* |
|---:|---:|---:|---:|
| 60 | ≈30.56 | ≈29.44 | ≈60.04 |
| 80 | ≈39.58 | ≈40.42 | ≈68.52 |
| 100 | ≈48.66 | ≈51.34 | ≈74.50 |

Ключовий висновок: додатковий ресурс збільшує оптимальний результат, але приріст поступово зменшується.
