# T1.L4. Класифікація методів математичного моделювання

**Цільова аудиторія:** ад’юнкти  
**Статус:** CONTENT STABLE після проходження перевірок  

## Навчальна мета

Сформувати здатність обирати математичний метод не за назвою бібліотеки, а за структурою дослідницької задачі та типом очікуваного результату.

## Навчальні питання

1. Основні методи математичного моделювання та ознаки їх застосування.
2. Вибір методу й Python-інструменту відповідно до постановки задачі.

## Ключовий принцип

**Problem structure → method → Python tool → verification → interpretation.**

Не існує універсальної бібліотеки або методу, який є найкращим для всіх задач.

## Method selection matrix

| Постановка | Метод | Python | Результат |
|---|---|---|---|
| знайти корінь рівняння | чисельний | SciPy `root_scalar` | числове значення |
| отримати точний вираз | аналітичний/символьний | SymPy | формула |
| знайти найкраще рішення за обмежень | оптимізація | SciPy `linprog` | оптимальний план |
| оцінити ризик за невизначеності | Monte Carlo | NumPy | розподіл/ймовірність |
| знайти критичний маршрут | мережевий | NetworkX | шлях/структура |
| вибрати альтернативу за кількома критеріями | MCDA | pandas/NumPy | рейтинг |

## Шість міні-кейсів

### Case A — Numerical root finding

Знайти момент часу `t`, коли функція

`f(t) = 120 - 6t - 0.2t^2`

досягає нуля.

**Метод:** чисельне знаходження кореня.  
**Інструмент:** `scipy.optimize.root_scalar`.

### Case B — Symbolic analysis

Для тієї самої функції знайти аналітичний вираз коренів.

**Метод:** символьний.  
**Інструмент:** SymPy.

### Case C — Linear optimization

Максимізувати

`F = 8x1 + 6x2`

за умов:

- `x1 + x2 <= 100`;
- `3x1 + 2x2 <= 240`;
- `x1, x2 >= 0`.

**Метод:** лінійне програмування.  
**Інструмент:** `scipy.optimize.linprog`.

### Case D — Monte Carlo risk

Оцінити ймовірність того, що сумарне споживання за 20 кроків перевищить 120 одиниць, якщо однокрокове споживання є випадковим.

**Метод:** Monte Carlo.  
**Інструмент:** NumPy RNG.

### Case E — Network method

Для графа робіт визначити критичний шлях.

**Метод:** мережевий.  
**Інструмент:** NetworkX.

### Case F — Multi-criteria decision analysis

Порівняти 3 альтернативи за критеріями cost, time, reliability.

**Метод:** weighted sum.  
**Інструмент:** pandas + NumPy.

## Критерії вибору методу

Перед вибором інструменту ад’юнкт відповідає на 6 питань:

1. Який тип результату потрібен: число, формула, оптимум, розподіл, шлях чи рейтинг?
2. Є невизначеність чи ні?
3. Є обмеження та цільова функція?
4. Чи важлива структура зв’язків між об’єктами?
5. Чи є кілька критеріїв одночасно?
6. Чи існує аналітичне рішення, яке можна використати для verification?

## Практичний результат

Ад’юнкт отримує 6 коротких постановок і для кожної має:

1. визначити клас методу;
2. обґрунтувати вибір;
3. обрати Python-бібліотеку;
4. запустити мінімальну реалізацію;
5. провести sanity check;
6. пояснити, що означає результат і чого він не доводить.
