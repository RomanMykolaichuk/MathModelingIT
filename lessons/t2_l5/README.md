## Прикладна постановка

Є чотири альтернативи A–D. Кожна оцінюється за п’ятьма критеріями:

- `cost` — витрати;
- `time` — витрати;
- `reliability` — виграш;
- `capacity` — виграш;
- `risk` — витрати.

Базові ваги:
- витрати = 0.25;
- time = 0.20;
- reliability = 0.25;
- capacity = 0.20;
- risk = 0.10.

Мета — не просто отримати «переможця», а дослідити:
- як змінюється ранжування залежно від методу;
- наскільки рішення чутливе до ваг;
- чи є лідер стійким за помірної невизначеності оцінок ваг.

## Математична модель

Нехай є альтернативи `A_i`, критерії `C_j`, оцінки `x_ij`, ваги `w_j`, де:

`w_j >= 0`, `sum(w_j)=1`.

### WSM

Після нормалізації всі критерії переводяться в шкалу [0,1], де більше = краще.

Для виграш-критерію:

`r_ij = (x_ij - min x_j)/(max x_j - min x_j)`

Для витрати-критерію:

`r_ij = (max x_j - x_ij)/(max x_j - min x_j)`

Підсумкова оцінка:

`S_i = sum_j w_j * r_ij`

### TOPSIS

1. Векторна нормалізація.
2. Зважування.
3. Формування ideal best та ideal worst.
4. Відстані до обох ідеальних точок.
5. Closeness coefficient:

`C_i = D_i^- / (D_i^+ + D_i^-)`

Чим більше `C_i`, тим краща альтернатива.

## базовий сценарій

WSM:
`C > D > B > A`

TOPSIS:
`C > A > D > B`

Це не помилка. Методи по-різному визначають «кращість».

## чутливість

Змінюємо вагу `reliability` від 0.10 до 0.45, а решту ваг пропорційно перенормовуємо.

При `w_reliability = 0.10` WSM обирає **B**, тоді як TOPSIS усе ще обирає **C**.

Отже, ранжування є функцією:
`data + criterion types + weights + aggregation method`.

## стійкість

Ваги моделюються як випадкові за Dirichlet-розподілом навколо базовий сценарій.

Для `n=3000`, `concentration=80`, `seed=2026`:
- WSM: C перемагає приблизно у 94% запусків;
- TOPSIS: C перемагає приблизно у 85% запусків.

Це вже не «один рейтинг», а оцінка стійкості рішення.

## Ключова інтерпретація

Не можна робити висновок «C — об’єктивно найкраща альтернатива».
Коректніше:

> За заданими критеріями, вагами та двома обраними методами C є базовим лідером і демонструє високу, але не абсолютну стійкість до помірних змін ваг.
