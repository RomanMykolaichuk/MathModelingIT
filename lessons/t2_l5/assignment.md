# Практичне завдання T2.L5

## Мета
Побудувати та дослідити багатокритеріальну модель вибору.

## Обов’язкова частина

1. Завантажити `alternatives.csv` та `criteria.csv`.
2. Визначити, які критерії є `benefit`, а які `cost`.
3. Перевірити суму ваг.
4. Побудувати WSM.
5. Побудувати TOPSIS.
6. Порівняти rankings.
7. Провести чутливість аналіз для одного критерію.
8. Провести стійкість аналіз для невизначених ваг.
9. Побудувати щонайменше 2 змістовні візуалізації.
10. Сформулювати дослідницький висновок.

## Контрольні базовий сценарій-результати

WSM:
`C > D > B > A`

WSM оцінка для C ≈ `0.6167`.

TOPSIS:
`C > A > D > B`

TOPSIS оцінка для C ≈ `0.5869`.

## Дослідницькі питання

1. Чому WSM і TOPSIS по-різному ранжують A та D?
2. Що станеться, якщо `cost` помилково вважати виграш-критерієм?
3. Які ваги є критичними для стабільності першого місця?
4. Чи достатньо показати лише базовий сценарій ранжування у дисертації?
5. Який мінімальний чутливість аналіз необхідний для науково обґрунтованого висновку?

## перенесення в дослідження

Створіть власну decision matrix з 3–7 альтернативами та 4–8 критеріями.

У звіті:
- предметна постановка;
- decision matrix;
- criterion types;
- ваги;
- WSM;
- TOPSIS;
- чутливість;
- стійкість;
- інтерпретація;
- limitations.
