# Практичне завдання T2.L5

## Мета
Побудувати та дослідити багатокритеріальну модель вибору.

## Обов’язкова частина

1. Завантажити `alternatives.csv` та `criteria.csv`.
2. Визначити, які критерії є `benefit`, а які `cost`.
3. Перевірити суму ваг.
4. Побудувати WSM.
5. Побудувати TOPSIS.
6. Порівняти rankings.
7. Провести sensitivity analysis для одного критерію.
8. Провести robustness analysis для невизначених ваг.
9. Побудувати щонайменше 2 змістовні візуалізації.
10. Сформулювати дослідницький висновок.

## Контрольні baseline-результати

WSM:
`C > D > B > A`

WSM score для C ≈ `0.6167`.

TOPSIS:
`C > A > D > B`

TOPSIS score для C ≈ `0.5869`.

## Дослідницькі питання

1. Чому WSM і TOPSIS по-різному ранжують A та D?
2. Що станеться, якщо `cost` помилково вважати benefit-критерієм?
3. Які ваги є критичними для стабільності першого місця?
4. Чи достатньо показати лише baseline ranking у дисертації?
5. Який мінімальний sensitivity analysis необхідний для науково обґрунтованого висновку?

## Research transfer
