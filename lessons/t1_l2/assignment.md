# Практичне завдання — T1.L2

## Мета

На одному об’єкті показати, як різні класи математичних моделей дають різний тип результату та потребують різної інтерпретації.

## Частина 1. Класифікація

Для кожної з наведених моделей визначте ознаки:

1. `S(t)=S0-vt`;
2. `C_k ~ N(mu, sigma^2)`;
3. `S[k+1]=max(0,S[k]-C[k])`;
4. 3000 повторних запусків моделі з оцінкою розподілу `T`.

Для кожної моделі вкажіть:

- детермінована чи стохастична;
- статична чи динамічна;
- дискретна чи неперервна;
- аналітична чи імітаційна;
- тип результату.

## Частина 2. Baseline

Використайте:

- `S0=120`;
- `mu=6`;
- `sigma=1.5`;
- `horizon=21`.

1. Обчисліть детермінований час вичерпання.
2. Побудуйте детерміновану траєкторію.
3. Побудуйте дві стохастичні траєкторії з різними seed.
4. Поясніть, чому траєкторії відрізняються.
5. Повторіть один seed і підтвердьте відтворюваність.

Контрольне значення детермінованої моделі:

`T = 20`.

## Частина 3. Monte Carlo

1. Виконайте не менше 3000 запусків.
2. Оцініть імовірність вичерпання ресурсу до кінця горизонту.
3. Обчисліть середній та медіанний крок вичерпання для реалізацій, у яких вичерпання відбулося.
4. Побудуйте гістограму.
5. Порівняйте результат із детермінованим прогнозом.

Для baseline при `seed=2026` очікувана оцінка імовірності — близько `0.80`.

## Частина 4. Сценарний аналіз

Дослідіть:

- `sigma=0.5`;
- `sigma=3.0`;
- `mu=7.0`.

Для кожного сценарію зафіксуйте:

- детермінований час вичерпання;
- Monte Carlo probability of exhaustion;
- середній/медіанний крок;
- зміни форми розподілу.

Поясніть окремо:

> Чим відрізняється вплив зміни середнього значення від впливу зміни дисперсії?

## Частина 5. Verification

Перевірте:

- `S0=120`, `v=6` → `T=20`;
- `[20, 15, 8, 0]` для ручного дискретного прикладу;
- однаковий seed → однакові випадкові значення;
- запас не стає від’ємним;
- ймовірність належить `[0,1]`.

## Частина 6. Інтерпретація

Дайте відповіді:

1. Чому одна стохастична траєкторія не є достатньою для оцінки ризику?
2. Чому Monte Carlo не «передбачає майбутнє», а оцінює наслідки прийнятих припущень?
3. Що саме означає `probability_exhausted ≈ 0.80`?
4. Які припущення моделі найсильніше обмежують достовірність такого висновку?
