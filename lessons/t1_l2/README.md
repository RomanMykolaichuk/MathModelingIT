## Навчальна мета

Сформувати здатність не просто називати класи математичних моделей, а пояснювати, **як зміна класу моделі змінює математичну постановку, програмну реалізацію, характер результату та межі висновків**.

Ключова ідея заняття:

> Один і той самий об’єкт можна моделювати по-різному залежно від дослідницького питання, доступних даних і того, яку невизначеність необхідно врахувати.

## Навчальні питання

### 1. Класифікація математичних моделей та її практичний зміст

Розглядаються ознаки:

- детерміновані / стохастичні;
- статичні / динамічні;
- дискретні / неперервні;
- лінійні / нелінійні;
- аналітичні / імітаційні;
- описові / оптимізаційні.

Класифікація використовується не як перелік термінів, а як відповідь на питання:

1. Які припущення закладено в модель?
2. Яким є її результат: одне значення, траєкторія чи розподіл?
3. Який Python-підхід потрібен для реалізації?
4. Які висновки модель дозволяє робити?

### 2. Реалізація різних класів моделей засобами Python

Один об’єкт — запас ресурсу — подається у чотирьох формах:

1. **детермінована неперервна модель**;
2. **стохастична модель споживання**;
3. **дискретна динамічна модель стану запасу**;
4. **імітаційна Monte Carlo модель**, що формує розподіл результатів.

---

# Наскрізний кейс заняття

Нехай початковий запас ресурсу:

\[
S_0 = 120.
\]

Середня інтенсивність витрачання:

\[
\bar{v}=6
\]

одиниць за крок часу.

## 1. Детермінована модель

Якщо витрачання є сталим:

\[
S(t)=\max(0,S_0-vt).
\]

Час вичерпання:

\[
t^*=\frac{S_0}{v}=\frac{120}{6}=20.
\]

Результат моделі — **одна прогнозована траєкторія**.

## 2. Стохастична модель

Нехай фактичне споживання на кожному кроці є випадковим:

\[
C_k \sim \mathcal{N}(\mu,\sigma^2),
\]

де:

\[
\mu=6,\qquad \sigma=1.5.
\]

Негативні значення, які можуть виникнути у нормальному розподілі, обрізаються до нуля:

\[
C_k=\max(0,C_k).
\]

Результат окремого запуску — **одна випадкова реалізація процесу**.

## 3. Дискретна динамічна модель

Стан запасу змінюється покроково:

\[
S_{k+1}=\max(0,S_k-C_k).
\]

Тут наступний стан залежить від попереднього стану та поточного споживання.

Результат — **траєкторія станів системи**.

## 4. Monte Carlo

Один стохастичний запуск не описує всю невизначеність. Тому модель повторюється багато разів.

Для кожного запуску фіксуємо крок вичерпання:

\[
T^{(r)}, \quad r=1,\dots,N.
\]

Далі оцінюємо:

- імовірність вичерпання до заданого горизонту;
- середній крок вичерпання;
- медіану;
- розподіл можливих моментів вичерпання.

Для baseline:

- \(S_0=120\);
- \(\mu=6\);
- \(\sigma=1.5\);
- горизонт — 21 крок;
- Monte Carlo — 3000 запусків;
- seed — 2026.

Контрольний результат:

- детермінований час вичерпання: **20.0**;
- оцінена імовірність вичерпання до кроку 21: близько **0.80**;
- умовне середнє для реалізацій, де ресурс вичерпано: близько **20.1**.

Це демонструє принципову відмінність:

> детермінована модель відповідає «коли ресурс вичерпається за прийнятих сталих умов?», а Monte Carlo — «яким є розподіл можливих результатів за наявності невизначеності?».

# Припущення та межі моделі

Модель є навчальною. Приймається, що:

- середній темп витрачання сталий;
- випадкові значення споживання незалежні між кроками;
- розподіл параметризовано лише через середнє та стандартне відхилення;
- поповнення ресурсу відсутнє;
- зміна середовища не впливає на параметри;
- після досягнення нуля запас не може стати від’ємним.

Модель **не дозволяє** автоматично стверджувати, що нормальний розподіл є адекватним для реального процесу. Тип розподілу має обґрунтовуватися даними або предметними припущеннями.

# Структура Python-моделі

```text
parameters
    ↓
deterministic_stock()
    ↓
one deterministic trajectory

parameters + seed
    ↓
stochastic_consumption()
    ↓
discrete_stock_path()
    ↓
one stochastic trajectory

parameters + many random runs
    ↓
monte_carlo_exhaustion_times()
    ↓
distribution of outcomes
    ↓
summarize_exhaustion()
```

Код винесений у `src/model.py`, а сценарний запуск — у `src/experiment.py`.

# Verification / sanity checks

Заняття містить такі перевірки:

1. Для `S0=120`, `v=6` детермінований час вичерпання має бути `20`.
2. Для ручного дискретного прикладу:
   - початковий запас `20`;
   - витрати `[5, 7, 10]`;
   - траєкторія повинна бути `[20, 15, 8, 0]`.
3. Однаковий `seed` повинен давати однакову стохастичну траєкторію.
4. Запас ніколи не може бути від’ємним.
5. Monte Carlo з однаковим seed має бути відтворюваним.
6. Імовірність події повинна лежати у межах `[0,1]`.
