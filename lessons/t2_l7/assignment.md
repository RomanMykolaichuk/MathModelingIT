# Практичне завдання T2.L7

## Мета

Виконати завершений відтворюваний мінідослідження experiment за шаблоном заняття.

## Частина A. дослідницьке питання та hypothesis

1. Сформулюйте дослідницьке питання.
2. Сформулюйте одну перевірювану гіпотезу.
3. Вкажіть, який саме модельний результат може підтримати або послабити цю гіпотезу.

## Частина B. дані and модель

1. Завантажте `synthetic_observations.csv`.
2. Опишіть змінні та параметри моделі.
3. Поясніть припущення моделі `dS/dt = q - kS`.
4. Вкажіть, які аспекти реальної системи модель ігнорує.

## Частина C. калібрування

1. Оцініть `q` та `k`.
2. Побудуйте fitted trajectory.
3. Обчисліть RMSE.
4. Поясніть, чому «малий RMSE» не є доказом істинності моделі.

## Частина D. перевірка

Порівняйте аналітичну траєкторію з `solve_ivp` та наведіть максимальну абсолютну похибку.

## Частина E. Scenario experiment

Змініть `q` у межах 80–120% від базовий сценарій.

Для кожного сценарію обчисліть:
- equilibrium;
- `S(horizon)`;
- time to threshold.

Побудуйте щонайменше один графік.

## Частина F. невизначеність

Виконайте bootstrap не менше ніж для 300 повторів.

Для `time_to_threshold` наведіть:
- mean;
- median;
- 2.5 percentile;
- 97.5 percentile.

## Частина G. дослідження conclusion

Підготуйте висновок 250–350 слів, у якому окремо зазначте:
- що показала модель;
- що показав чутливість аналіз;
- що показав bootstrap;
- які твердження допустимі;
- які твердження були б надмірними;
- що потрібно для валідації на реальних даних.

## Частина H. перенесення в дослідження

Складіть аналогічний процес для власної дисертаційної задачі.

## Deliverables

1. Заповнений `practice.ipynb`.
2. Не менше 2 графіків.
3. Таблиця сценаріїв.
4. Bootstrap підсумок.
5. дослідження conclusion.
6. перенесення в дослідження block.

## Оцінювання

- дослідницьке питання + hypothesis — 15%;
- модель/дані formalization — 15%;
- калібрування — 15%;
- перевірка — 10%;
- scenario/чутливість experiment — 15%;
- невизначеність аналіз — 15%;
- scientific інтерпретація and limitations — 10%;
- відтворюваність/перенесення в дослідження — 5%.

**Принцип:** результат без опису припущення, невизначеність і перевірка не вважається повним науковим результатом.
