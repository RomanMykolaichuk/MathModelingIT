2. **Інтеграція символьних і чисельних методів у Python: SymPy → NumPy/SciPy → verification → visualization.**

## Очікуваний результат

Ад'юнкт уміє:

- задавати змінні, параметри, рівняння та диференціальні рівняння у SymPy;
- виконувати `solve`, `diff`, `integrate`, `simplify`, підстановки;
- отримувати аналітичний розв'язок моделі;
- переводити символьний вираз у чисельну функцію через `lambdify`;
- перевіряти аналітичний результат незалежним чисельним методом SciPy;
- виконувати параметричний експеримент і чутливісний аналіз;
- пояснювати межі застосовності символьного і чисельного підходів.

## Центральний кейс

Розглядається узагальнена динамічна система з постійним надходженням ресурсу та пропорційними втратами:

\[
\frac{dS}{dt}=q-kS,\qquad S(0)=S_0,
\]

де:

- \(S(t)\) — стан системи;
- \(q\) — постійна інтенсивність надходження;
- \(k>0\) — коефіцієнт пропорційних втрат;
- \(S_0\) — початковий стан.

Модель навмисно є абстрактною і використовує синтетичні параметри.

## 1. Символьний рівень

SymPy дозволяє записати модель у формі, близькій до математичного запису:

```python
t = sp.symbols("t", nonnegative=True)
q, k = sp.symbols("q k", positive=True)
S = sp.Function("S")

ode = sp.Eq(sp.diff(S(t), t), q - k*S(t))
```

### Рівноважний стан

З умови

\[
q-kS^*=0
\]

отримуємо

\[
S^*=\frac{q}{k}.
\]

### Аналітичний розв'язок

\[
S(t)=\frac{q}{k}+\left(S_0-\frac{q}{k}\right)e^{-kt}.
\]

### Символьна verification

Якщо підставити розв'язок у вихідне диференціальне рівняння, залишок

\[
R(t)=\frac{dS}{dt}-(q-kS)
\]

має спроститися до нуля.

```python
residual = sp.simplify(sp.diff(solution, t) - (q - k*solution))
assert residual == 0
```

Це важлива відмінність від простої перевірки кількох чисел.

## 2. Символьне інтегрування

Для дослідницьких задач може бути потрібен не тільки стан у конкретний момент, а накопичена величина:

\[
A(T)=\int_0^T S(t)\,dt.
\]

SymPy отримує вираз аналітично, після чого його можна підставляти у подальші розрахунки.

## 3. Символьна чутливість

Для рівноважного стану

\[
S^*=\frac{q}{k}
\]

отримуємо:

\[
\frac{\partial S^*}{\partial q}=\frac{1}{k},
\qquad
\frac{\partial S^*}{\partial k}=-\frac{q}{k^2}.
\]

Таким чином, система комп'ютерної математики може працювати не тільки з числовим результатом, а й з **структурою залежностей**.

## 4. Перехід SymPy → NumPy

`lambdify` перетворює символьний вираз на чисельну функцію:

```python
fn = sp.lambdify((t, q, k, S0), solution, modules="numpy")
```

Після цього той самий аналітичний вираз можна обчислювати для масивів часу, будувати графіки та виконувати сценарні експерименти.

## 5. Незалежна чисельна verification

Аналітичний розв'язок перевіряється через `scipy.integrate.solve_ivp`.

Це дозволяє порівняти:

1. символьний вираз SymPy;
2. чисельну функцію після `lambdify`;
3. незалежне чисельне інтегрування SciPy.

Для коректної реалізації три траєкторії мають практично збігатися.

## 6. Baseline

Використовуються синтетичні параметри:

```text
q  = 12
k  = 0.10
S0 = 20
```

Отримуємо:

\[
S^*=120,
\]

\[
S(10)\approx83.2121,
\]

\[
\int_0^{10} S(t)\,dt \approx 567.8794.
\]

Час досягнення рівня \(S=80\):

\[
t\approx9.1629.
\]

## 7. Параметричний експеримент

При незмінному \(q=12\) досліджується зміна \(k\):

| k | S* | S(10) |
|---:|---:|---:|
| 0.05 | 240 | 106.56 |
| 0.08 | 150 | 91.59 |
| 0.10 | 120 | 83.21 |
| 0.12 | 100 | 75.90 |
| 0.15 | 80 | 66.61 |

Ад'юнкт має пояснити результат не лише чисельно, а через формулу \(S^*=q/k\) та похідну \(-q/k^2\).

## 9. Verification hierarchy

```text
математична постановка
        ↓
символьний розв'язок
        ↓
символьний residual check
        ↓
lambdify
        ↓
чисельна реалізація
        ↓
незалежний solve_ivp
        ↓
порівняння похибки
        ↓
сценарний експеримент
        ↓
інтерпретація
```

## 10. Межі застосовності

Модель припускає:

- постійне \(q\);
- сталий коефіцієнт \(k\);
- лінійну залежність втрат від стану;
- відсутність затримок, порогів та взаємодій з іншими змінними.

Тому успішне аналітичне розв'язання не означає автоматичної адекватності моделі реальному об'єкту.
