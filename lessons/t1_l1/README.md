## 1. Problem

Розглядається умовна система, у якій на початку спостереження є запас ресурсу `S0`. Ресурс витрачається з постійною інтенсивністю `v`. Необхідно визначити:

- як змінюється залишок ресурсу в часі;
- коли ресурс буде вичерпаний;
- як зміна інтенсивності витрачання впливає на тривалість функціонування системи.

Приклад навмисно абстрактний. Під ресурсом можна розуміти запас матеріалу, енергії, часу, бюджету, пропускної спроможності або іншої вимірюваної величини.

## 2. Чотири форми представлення однієї моделі

### 2.1. Словесна форма

Початковий запас ресурсу поступово зменшується. За кожну одиницю часу витрачається однакова кількість ресурсу.

### 2.2. Математична форма

Ідеалізована лінійна модель:

\[
S(t)=S_0-vt,
\]

де:

- \(S(t)\) — залишок ресурсу в момент часу \(t\);
- \(S_0\) — початковий запас;
- \(v\) — інтенсивність витрачання;
- \(t\) — час.

Для фізично змістовної версії додаємо обмеження:

\[
S(t)\ge 0.
\]

Тоді:

\[
S_{phys}(t)=\max(0,S_0-vt).
\]

Час теоретичного вичерпання для `v > 0`:

\[
t_* = \frac{S_0}{v}.
\]

### 2.3. Алгоритмічна форма

1. Задати `S0`, `v` і часовий інтервал.
2. Для кожного `t` обчислити `S0 - v*t`.
3. Якщо використовується фізичне обмеження, замінити від’ємні значення на нуль.
4. Зберегти результати.
5. Побудувати графік.
6. Порівняти базовий та змінений сценарії.
7. Сформулювати висновок про вплив параметра `v`.

### 2.4. Програмна форма

```python
def resource(t, s0, rate):
    return max(0, s0 - rate * t)
```

У навчальному коді функція розширена для роботи з масивами NumPy, перевірки коректності параметрів та відокремлення моделі від експерименту.

## 3. Припущення моделі

1. Інтенсивність витрачання `v` є сталою.
2. Початковий запас `S0` відомий точно.
3. Зовнішнє поповнення ресурсу відсутнє.
4. Втрати, похибки вимірювання та випадкові впливи не враховуються.
5. Час є незалежною змінною.
6. Для фізично обмеженої моделі залишок ресурсу не може бути від’ємним.

## 4. Межі застосовності

Модель не слід безпосередньо використовувати, якщо:

- інтенсивність витрачання істотно змінюється в часі;
- ресурс поповнюється;
- існують порогові або нелінійні ефекти;
- параметри мають істотну невизначеність;
- поведінка системи залежить від зворотного зв’язку.

Це принциповий момент заняття: **простота моделі є перевагою лише тоді, коли її припущення відповідають дослідницькій задачі.**

## 5. Computational experiment

### Базовий сценарій

- `S0 = 120`
- `v = 8`
- часовий горизонт: `0..20`

Очікуваний час вичерпання: `120/8 = 15`.

### Змінений сценарій

Зменшуємо інтенсивність витрачання:

- `S0 = 120`
- `v = 5`

Очікуваний час вичерпання: `120/5 = 24`.

У межах горизонту `0..20` ресурс у другому сценарії не вичерпується.

### Аналіз чутливості

Досліджуються значення `v = [4, 6, 8, 10, 12]`.

Основне дослідницьке питання:

> Як зміна одного параметра моделі впливає на поведінку системи та досліджуваний результат?

## 6. Verification / sanity checks

Для моделі передбачені такі перевірки:

1. При `t = 0` повинно виконуватися `S(0) = S0`.
2. При `v = 0` запас не змінюється, а час вичерпання є нескінченним.
3. Для `S0 = 120`, `v = 8` теоретичний час вичерпання дорівнює `15`.
4. Без фізичного обмеження формула може дати від’ємне значення; це демонструє різницю між математичним виразом і змістовно коректною моделлю.
5. Від’ємний час, від’ємний початковий запас та від’ємна інтенсивність витрачання відхиляються валідацією.
