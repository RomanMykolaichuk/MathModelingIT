# Практичне завдання — T1.L1

## Мета

Перетворити коротку прикладну постановку на формалізовану математичну модель, реалізувати її у Python і провести мінімальний обчислювальний експеримент.

## Частина A. Від постановки до моделі

Для базового кейсу `S(t)=S0-vt`:

1. Поясніть зміст `S(t)`, `S0`, `v`, `t`.
2. Визначте незалежну і залежну змінні.
3. Визначте параметри.
4. Запишіть щонайменше три припущення.
5. Поясніть, чому значення `S(t) < 0` є математично можливим, але змістовно проблемним.
6. Запропонуйте фізично обмежену версію моделі.

## Частина B. Python

Відкрийте `notebooks/practice.ipynb` і виконайте завдання TODO.

Мінімально необхідно:

- реалізувати або викликати функцію моделі;
- провести базовий сценарій;
- змінити параметр `rate`;
- побудувати графік;
- визначити час вичерпання;
- перевірити `S(0)=S0`;
- виконати аналіз чутливості для не менше ніж п’яти значень `rate`.

## Частина C. Інтерпретація

Дайте відповіді:

1. Який параметр найбільше впливає на результат у цій моделі?
2. Чи можна за графіком довести причинно-наслідковий зв’язок?
3. Які твердження виходять за межі моделі?
4. Які додаткові дані були б необхідні для реалістичнішої моделі?
5. За якої умови лінійна модель стає непридатною?

## Частина D. Research transfer
