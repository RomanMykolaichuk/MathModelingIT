# етап підготовки презентацій

Цей каталог фіксує окремий презентаційний контур дисципліни **MathModelingIT**.

Презентації створюються тільки після стабілізації навчально-обчислювального контуру:

`lesson package -> verified code -> demo notebook -> practice notebook -> presentation brief -> slide plan -> narrative -> PPTX -> visual QA`

## Поточний стан

- 11/11 занять мають `content_stable`.
- підсумковий проєкт має `content_stable`.
- Course CI зелений: 11 заняття structures, підсумковий проєкт, 98 Python tests, 12 demo блокноти Jupyter.
- Створено початковий пакет із 11 PPTX-презентацій у єдиному академічному стилі.

## Принципи презентацій

1. Презентація не замінює блокнот Jupyter і не дублює код повністю.
2. Кожна презентація пояснює: **навіщо модель потрібна, як вона формалізується, як реалізується в Python, як перевіряється і як інтерпретується**.
3. Числові результати беруться з перевірених пакети занять.
4. Кожна презентація завершується дослідження-Перенесення блоком для ад’юнктів.
5. PPTX-файли можуть генеруватися як артефакти релізу або додаватися окремо після затвердження стилю.

## Структура одного презентація

Типовий презентація має 8 слайдів:

1. Назва
2. заняття logic
3. Mathematical модель
4. Реалізація в Python
5. обчислювальний експеримент
6. перевірка and відтворюваність
7. Практика and дослідження Перенесення
8. підсумок

## Наступний етап

Після перегляду початкового PPTX-пакета необхідно:

- уточнити стиль, якщо потрібно;
- додати заняттєві графіки безпосередньо з `outputs/` пакети занять;
- за потреби створити повні сценарії усного супроводу для усного супроводу;
- зробити візуальна перевірка кожної презентації окремо.
